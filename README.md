# Leaf-First Tomato Disease Assistant

ECE 539 Fall 2026 integration project. We investigate whether automatically locating and cropping a tomato leaf reduces background shortcuts and improves disease classification on field photos.

The proposed pipeline combines a leaf localizer, a 10-class disease classifier, calibrated confidence and Grad-CAM explanations. It compares cropped leaves with full-photo classification and can request a retake or recommend consulting an expert when uncertain.
